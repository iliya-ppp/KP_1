# 1. Постановка задачи

## Анализ задания
Цель данной подзадачи — разработка программы для оперативного контроля и анализа телеметрических данных датчика давления. 

Программа реализует пошаговый алгоритм обработки поступающих значений , выполняя все расчеты сразу.

## Входные и выходные параметры
*   **Входные данные:** Последовательность вещественных чисел X (давление сырья в диапазоне от 1.0 до 12.0 бар), вводимая пользователем в интерактивном режиме (всего N=60 шагов).
*   **Выходные данные:** 
    *   Текущие значения индикатора процесса Q(X) для каждого шага.
    *   Текстовые маркеры технологического состояния («в норме» / «отклонение (ниже)» / «отклонение (выше)»).
    *   Итоговая статистическая сводка по целевому окну контроля (шаги с 11 по 37).

## Реализованная архитектура и ограничения
*   **Вычисление индикатора:** Расчет Q(X) выполняется на основе кусочно-заданной функции (линейная, логарифмическая и корневая ветки вычислений).
*   **Контроль параметров:** Вычисляемые значения Q(X) мгновенно сопоставляются со статическими границами технологического коридора (LCL = 42.1705, UCL = 46.6095) для немедленного вывода статуса.
*   **Статистический анализ:** Накопление аналитических данных по выбранному окну итераций (с 11 по 37 шаг) осуществляется с использованием метода: программа последовательно накапливает общую сумму (`sub_sum`) и счетчик элементов (`sub_count`), рассчитывая текущее среднее арифметическое на каждом шаге целевого диапазона.
*   **Проверка:** В код встроена проверка входного потока данных, блокирующая обработку символьных строк и выход за физический диапазон давления (1–12 бар) с автоматическим повтором текущего шага.
